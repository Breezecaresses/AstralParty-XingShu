# 星枢 0.2.0 正式版

本次正式发布包含桌面端与安卓端 `0.2.0`（更新序号 `2026112601`），配套 **`1.0.0-game-ui-r8.59`** / **`1.0.0-android-preview8.59`** 核心框架。

## 核心更新内容

- **恢复游戏内原版 UI 字体并保留 2x 高 DPI 画布超采样（r8.59）**：
  - 将「星枢功能中心（毛玻璃框架 v2 & 原版 UI 皮肤）」与全部子页面恢复为游戏原版 UI 字体，同时保留 `1080p` 逻辑根容器 + 自适应 `2x` 高 DPI 画布超采样，兼顾原版视觉统一与高清晰度。
- **修复点击「预览启动动画」闪退（v0.2.0）**：
  - 将 `replay_startup_splash` 与 `finish_splash_and_show_main` 改为异步 Tauri 命令，先等待旧开屏窗口释放并在 `splash` 窗口创建成功并显示后再隐藏主窗口，避免 Windows WebView2 同步 IPC 重入崩溃；
  - 始终在 `Layout` 监听 `xingshu:splash-finished` 事件，确保任意开屏开关状态下均可稳定重播入场动效。
- **精简「设置」页重复面板（v0.2.0）**：
  - 移除「设置」页内的「个性化与启动动画」区块，统一保留在「自定义 → 星枢自定义背景 → 背景与个性化」中配置。
- **桌面端「探索与筛选 / 全部模组」卡片对齐网页版星枢工坊（v0.2.0）**：
  - 支持点击整张模组卡片直接进入详情页弹窗，移除卡片上的「详情」「开关」「移除」操作按钮，并在右侧展示「已安装 / 已下载」状态提醒及下载量、表情回应数、展示图数与 SHA-256 核验图标；
  - 在卡片底部接入与网页版一致的角色表情回应栏（支持直接表态、切换表情与展开角色表情面板），「已安装 Mod」页面原有管理操作保持不变。
- **包含的近期重要改进（r8.58）**：
  - 毛玻璃 UI 零回闪/零闪烁渲染与 1080p 逻辑超采样；
  - 「怪物行动可视」「防御与卡牌点数提示」「自动化社交」「角色Buff显示」16 项模块化整合与旧 `.module` 向下兼容；
  - 「自定义 → 主页背景」16:9 游戏视口比例预览与原生时间加速速率补偿、星枢工坊网页版 `/extensions/plugin-guide` 插件接入指南联动。
